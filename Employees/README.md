## Хичээлийн тохиргооны файлыг ашиглах · Using a course setup file

AI Тархи фолдероо холбосон чатад хичээлийн тохиргооны файлыг (жишээ нь `AI-Personal-Assistant-Setup-MN.md`) оруулаад ингэж хэлнэ:

> Миний тархины AGENTS.md болон README.md-г уншаад энэ тохиргооны файлыг дага. Асуулт, туршилтуудыг алхам алхмаар хөтөлж, бэлэн болсон ажилтны зааврыг Employees-д хадгал. Миний Context файлуудыг ашигла. Юу холбогдож, юуг туршсан, юу нь хараахан болоогүйг хэл.

*In English: "Read AGENTS.md and README.md in my brain, then follow this setup file. Guide me through its questions and testing. Save my finished personalized employee instructions in Employees, reference my shared context, and tell me what has and has not been connected or tested."*

Тохиргооны файл бол ярилцлагын хөтөч. Үр дүн нь таны хувийн ажилтны заавар. Цаашид тэр зааврыг ашиглана. Ажилтнаа дахин тохируулахыг хүсэхгүй бол ярилцлагыг дахин хийх шаардлагагүй.
*The setup file guides the interview; the output is your personal employee profile. Keep using that profile; don't repeat the interview unless reconfiguring.*

Ажилтны заавар ажлыг тайлбарлана. Дахин ашиглах аргачлалыг Skills-ээс, одоогийн ажлыг Projects-оос лавлаж болно. Файлын нэрийн жишээ: `My-AI-Personal-Assistant.md`, `Content-Strategist.md` (эдгээр нь жишээ, суусан ажилтан биш).

Зөвхөн эхлэх бүтэц хэрэгтэй бол [Employee-Profile-Template.md](Employee-Profile-Template.md)-г ашиглана. Хичээлийн тохиргооны файл илүү дэлгэрэнгүй шаардлагатай бол тэр нь давуу эрхтэй. Жинхэнэ ажилтан бүрт доор нэг богино холбоос нэмнэ.
*Use the template only as a starting outline; a detailed course setup file takes precedence. Add one link below for each real employee.*
