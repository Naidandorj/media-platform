# Таны төслүүд · Your projects

Үргэлжилсэн ажилд төслийн фолдер үүсгэнэ. Жишээ нь вэбсайт нээх, илтгэл бэлтгэх, аялал төлөвлөх. Богино асуулт бүрт төсөл үүсгэх шаардлагагүй.
*Create a project folder for ongoing work, such as a website launch, presentation, or trip plan. Not for every quick question.*

Claude-д ингэж хэлнэ:

> [зорилго]-д зориулж төсөл үүсгэ. Хэрэгтэй мэдээллээ асууж, бриф болон handoff үүсгээд, ажлыг тэр төслийн фолдерт хадгал.

*In English: "Set up a project for [goal]. Ask for the information you need, create a brief and handoff, and save the work in that project folder."*

[Project-Template](Project-Template/)-ийг эхлэх бүтэц болгон ашиглана. Энэ бол хоосон загвар, идэвхтэй төсөл биш. Хэрэгтэй үед хуулж, өөрийнхөөрөө болгоно. Загвар дотор хувийн мэдээлэл бүү бөглө.
*Use the template as starting structure. Copy and personalize it; don't fill the template itself.*

- **BRIEF.md** — зорилго, хэнд зориулсан, шаардлага, эх материал, одоогийн шийдвэрүүд. *Goal, audience, requirements, sources, decisions.*
- **HANDOFF.md** — төлөв, бэлэн болсон файлууд, нээлттэй асуудал, дараагийн алхам. *Status, outputs, open issues, next step.*
- **Бусад файлууд** — ноорог, илтгэл, зураг, хүснэгт, эх материал. *Drafts, presentations, images, spreadsheets, sources.*

Таны болон ажлын тань ерөнхий мэдээлэл Context-д үлдэнэ. Давхардуулахгүй, холбоно. Claude өөрчлөлт хийхээсээ өмнө төслийн файлуудыг уншиж, батлагдсан хувилбаруудыг хадгална.
*Keep general context in Context and link to it. The AI reads current project files before changes and preserves approved versions.*
