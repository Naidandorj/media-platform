## Хэрхэн шинэчлэх вэ · How to update

Чухал хүсэл сонголт бүрт дүрэм, хамрах хүрээ, баталсан огноог бичнэ. Бүтцийн жишээ (таны хүсэл сонголт биш): «Хүсэл сонголт: [дүрэм]. Хамрах хүрээ: [хаана]. Баталсан: [огноо].»
*For each meaningful preference, state the rule, its scope, and when confirmed. Example structure, not a user preference: "Preference: [rule]. Applies to: [scope]. Confirmed: [date]."*

Зөвхөн нэг ажилд хамаарах саналыг тухайн төсөлд хадгална. Хүсэл сонголт өөрчлөгдвөл хуучин дүрмийг шинээр солино, зөрчилтэй хоёр дүрэм зэрэг үлдээхгүй. Хамрах хүрээ тодорхойгүй бол асууна.
*Task-only feedback belongs in the relevant project. Replace a changed preference rather than leaving contradictory rules. Ask when scope is unclear.*
